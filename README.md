## Linear Regression: simple tool to start understanding data.

How historical data can help to understand the present and prepare for the future?

Sometimes, starting with a trend line is a good choice.

In this example, evolution of net revenue of some chemical segments in Brazil along several years.

Three tools to draw linear trend lines:
- Excel: using standard formulas, also using Analysis Toolpak
- Power BI: just showing how easy and beautiful it is to make charts from data, not entering in creating DAX formulas to calculate slope and intercept.
- Python: showing regression line approach from different libraries (numpy, scipy, statsmodel, sklearn).
